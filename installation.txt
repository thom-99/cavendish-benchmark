Install Pixi, then create the locked workflow environment from the repository
root:

    pixi install

The environment is defined in pixi.toml. It includes inSVert, minimap2,
Badread, Sniffles2, cuteSV, dysgu, Truvari, samtools, bcftools, and the Python
and shell utilities used by the workflow. A system Bash is also required.

inSVert is installed directly from:

    https://github.com/thom-99/inSVert.git

inSVert's Python dependencies are resolved from that repository's
pyproject.toml rather than being duplicated in pixi.toml.
